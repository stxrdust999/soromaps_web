# 📚 Documentação — Soromaps

Bem-vindo à documentação do **Soromaps**. Toda a documentação do repositório está organizada em três frentes enxutas:

| Pasta | Propósito |
|---|---|
| **[`wiki/`](./wiki/00-home.md)** | Visão geral do projeto, proposta de produto, jornadas do explorador, governança, gamificação e ecossistema. |
| **[`adr/`](./adr/README.md)** | Architecture Decision Records — histórico imutável de decisões de design e arquitetura do front-end (`user/` e `admin/`). |
| **[`todo/`](./todo/README.md)** | Roteiro por módulo para a integração do front-end com a API (`soromaps_api`). |

> **Nota sobre documentação técnica de backend:** Diagramas de banco de dados (`.dbml`), ADRs da API e pendências de implementação de endpoints ficam diretamente no repositório da API (`../soromaps_api/Docs/`).
